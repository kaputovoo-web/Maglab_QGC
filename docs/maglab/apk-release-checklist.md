# Maglab APK 交付清单

## 最终交付范围（以最新用户要求为准）

最终 APK 必须覆盖全部旧模块，范围详见 [full-module-delivery.md](full-module-delivery.md)。以下阶段包只用于内部验证，不能替代最终交付，也不能在未迁移 Archive/采集/RTSP 等模块时宣称完成。

## 内部阶段验证范围

- 阶段测试包：已有简易 3D + 磁图页面；可编译打包，但磁图仍需真机验收。未完成规划功能不开放入口。
- 规划功能测试包：额外包含 LLM/Sketch 的可编辑、可保存重载任务，需要先完成下面的集成及离线行为验证。

后端参与编译不代表功能入口存在。当前设备仍为 simple-3d-amsl 测试包，后续模块包未安装。

## 规划功能包前置

- [ ] 接入规划 QML 资源，修正 editor/mapVisual URL，验证动态上下文及小屏布局。
- [ ] 在当前版本任务创建与加载分支接入 LLM/Sketch，并保持仅 Maglab 定制启用。
- [ ] 接入 LLM 配置页面及设置生命周期，检查密钥不出现在日志/源码中。
- [ ] 对四种策略和 Sketch 测量实际指令数量/序号，验证速度恢复、入口出口和高度模式。
- [ ] 验证保存重载、非法输入、对象移除、转原生 Survey、无 Home 等场景。
- [ ] 将策略输出失败传播到保存/上传前置校验；生成函数拒绝输出本身不能保证上传会被阻断。
- [ ] 录音权限、取消、停止收尾、网络超时/重试/销毁和响应大小限制验证。
- [ ] 用户审核生成任务后才允许手动上传；不自动执行。

## 打包与设备验收

- [ ] 明确本次包的功能范围；Archive/采集 UI/旧 RTSP 等未迁移模块不算完成。
- [ ] 补齐新增文案中文翻译，运行相关 lint 和项目测试；独立 smoke 不替代项目 Unit 测试。
- [ ] Android Release 全量增量构建退出 0，保留日志和构建配置。
- [ ] 使用兼容的签名证书对 APK 签名，检查签名与 zipalign；独立检查 native 库页对齐兼容性。
- [ ] 记录包名 org.maglab.groundcontrol.test、版本、文件路径及 SHA256。
- [ ] 用户确认无飞行任务、飞控链路断开后，再 adb install -r；不卸载、不清数据。
- [ ] 冷启动检查日志，验收磁图/PIP/小屏/文件加载、现有 3D，以及飞控连接和 GStreamer 视频回归。
- [ ] 保留旧 APK 和数据备份/导出说明，明确私有数据在卸载时会删除。

正式分发还需要确定长期签名密钥及版本递增策略，不能把 debug 签名测试包称为正式发布版；更换签名必须先评估覆盖安装兼容性，不能通过卸载规避。
